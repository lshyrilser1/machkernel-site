# machkernel.org

Source for [machkernel.org](https://machkernel.org), a short independent reference on the Mach kernel. Plain HTML and one stylesheet, no build step.

Corrections are welcome as issues or pull requests.

The site is in English and in Mexican Spanish (`es/`). Each English page has a Spanish twin with the same file name, the same ids and the same links. When you change one, change the other.
