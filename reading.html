Reading

Where it started

  • Accetta, Baron, Bolosky, Golub, Rashid, Tevanian, Young. Mach: A New Kernel Foundation for UNIX Development. USENIX Summer 1986. The best single introduction.
  • Rashid and Robertson. Accent: A Communication Oriented Network Operating System Kernel. SOSP 1981. The kernel Mach grew out of.
  • Draves, Jones, Thompson. MIG: The MACH Interface Generator. 1989.

Mach 3.0 and servers

  • Malan, Rashid, Golub, Baron. DOS as a Mach 3.0 Application. USENIX Mach Symposium, 1991.
  • Draves, Bershad, Rashid, Dean. Using Continuations to Implement Thread Management and Communication in Operating Systems. SOSP 1991.
  • Ford and Lepreau. Evolving Mach 3.0 to a Migrating Thread Model. USENIX Winter 1994.

Criticism

  • Liedtke. Improving IPC by Kernel Design. SOSP 1993. Argues that Mach's message passing was far slower than it needed to be. It led to the L4 family of kernels.

Archives and books

  • The CMU Mach publication archive, including the Mach Kernel Interface Manual.
  • Silberschatz, Galvin and Gagne, Operating System Concepts, appendix on the Mach system.
  • The Mach 4 project at the University of Utah.
